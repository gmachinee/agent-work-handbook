# agent-work-handbook

AI 에이전트와 코딩, 콘텐츠 제작, 아티클 작성을 수행할 때 사용하는 개인 작업 안내서입니다. 채택한 지침, 반복 작업 절차, 참고 자료, 검증한 사례를 Markdown으로 관리합니다.

## 시작하기

- **사람이 읽을 때:** 아래 자료 지도에서 작업에 필요한 문서를 찾습니다.
- **에이전트가 사용할 때:** [AGENTS.md](AGENTS.md)의 읽는 순서와 적용 기준을 확인합니다.
- **자료를 추가할 때:** [문서 형식](docs/document-format.md)을 읽고 [템플릿](templates/README.md)을 복사합니다.
- **RAG에 연결할 때:** [검색·활용 기준](docs/retrieval-policy.md)을 입력 계약으로 사용합니다.

## 자료 지도

| 종류 | 위치 | 내용 | 활용 방식 |
| --- | --- | --- | --- |
| 지침 | [knowledge/rules](knowledge/rules/README.md) | 채택한 작업·판단 기준 | 적용 범위가 맞으면 따름 |
| 작업 절차 | [knowledge/guides](knowledge/guides/README.md) | 준비 조건, 순서, 완료 기준 | 작업 수행에 활용 |
| 참고 자료 | [knowledge/references](knowledge/references/README.md) | 외부 자료의 요약, 출처, 해석 | 근거와 참고 자료로 활용 |
| 검증 사례 | [knowledge/patterns](knowledge/patterns/README.md) | 실제 확인한 방법, 조건, 결과 | 유사한 상황에서 재사용 |

각 종류의 하위 폴더에는 코딩, 테스트, 협업, 콘텐츠, 글쓰기, AI 등 필요한 주제를 둡니다. 여러 주제에 걸친 문서는 한 곳에 보관하고 태그와 관련 문서 링크로 연결합니다.

## 작성 중인 문서

- [한국어 정보성 콘텐츠 작성 지침](knowledge/rules/writing/korean-informational-writing.md) — `draft`. 카드뉴스·제품 소개·안내·개념 설명·내부 공유 등에 적용하는 공통 작성 기준입니다. 참고자료와 적용 범위는 같은 문서의 부록에 통합했습니다.
- [범용 UI/UX 표준 지침](knowledge/rules/design/universal-uiux.md) — `draft`. 특정 서비스·실행 환경·구현 수단에 의존하지 않는 요구사항 15개, 적합성 확인 기준 30개, 검수·판정·기록 방법을 한 문서로 관리합니다.

문서 등록과 소유자의 활성화, 개별 에이전트에 대한 적용은 구분합니다. Product Scout 등의 작업별 독자·톤·구성 지침과 수집·선별·발행 운영 지침은 이번 문서에 포함하지 않았습니다.

## 저장소 구조

```text
agent-work-handbook/
├── README.md                  # 자료 지도
├── AGENTS.md                  # 에이전트의 사용 기준
├── docs/                      # 문서 형식과 검색 기준
├── templates/                 # 종류별 작성 템플릿
├── inbox/                     # 수집한 자료와 초안
├── knowledge/
│   ├── rules/                 # 채택한 지침
│   ├── guides/                # 작업 절차
│   ├── references/            # 외부 자료와 해석
│   └── patterns/              # 검증한 사례
├── assets/                    # 문서에 연결된 첨부 자료
└── archive/                   # 사용을 마친 문서
```

## 자료를 추가하는 흐름

1. 링크, 메모, 아이디어를 `inbox/`에 모읍니다. 이 단계에서는 정식 문서 형식을 강제하지 않습니다.
2. 적절한 템플릿을 복사해 `knowledge/`의 해당 폴더에 `draft` 문서를 작성합니다.
3. 고유 ID, 요약, 적용 범위, 출처 또는 판단 근거를 채웁니다.
4. 소유자가 내용과 적용 조건을 검토한 뒤 `active`로 변경합니다.
5. 수정할 때 `updated`를 갱신하고, 내용을 다시 확인했다면 `reviewed_on`을 기록합니다.
6. 사용을 마친 문서는 `archived`로 변경하고 `archive/`로 이동합니다. 대체 문서가 있다면 관계와 링크를 남깁니다.

`active`는 현재 활용 대상이라는 뜻입니다. 참고 자료의 활성화와 작업 지침의 채택은 각각 해당 문서 종류의 기준을 따릅니다.

## 운영 원칙

- 한 문서는 하나의 질문, 판단 주제, 작업 또는 패턴을 다룹니다.
- 폴더는 역할을, 태그는 주제를 표현합니다.
- 원문에서 얻은 사실과 개인의 해석을 구분합니다.
- 공개할 수 있는 지침·요약·사례를 저장합니다. 예시는 공개용 데이터로 작성합니다.
- 문서 원본은 Git으로 관리하고, 검색 인덱스와 임베딩은 원본에서 재생성합니다.

## 라이선스

현재 별도의 재사용 라이선스는 지정하지 않았습니다. 외부 자료의 권리는 각 원저작자에게 있으며, 해당 자료의 출처와 이용 조건을 따릅니다.
