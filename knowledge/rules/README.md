# 지침

소유자가 채택할 작업·판단 기준을 보관합니다. 정식 문서의 `kind`는 `rule`입니다.

- `coding/`: 코드 작성과 설계 기준
- `testing/`: 제품 동작과 회귀를 검증하는 기준
- `collaboration/`: 에이전트 협업과 결과 전달 기준
- `content/`: 콘텐츠 제작·편집 기준
- `writing/`: 아티클 작성과 출처·문체 기준

[지침 템플릿](../../templates/rule.md)을 복사하고 적용 범위와 판단 근거를 작성합니다. 활성 규칙은 [검색·활용 기준](../../docs/retrieval-policy.md)에 따라 관련도 검색과 별도로 확보합니다.
