# 지식 문서

이 폴더에는 정식 문서 형식을 갖춘 지식 문서를 저장합니다.

- [지침](rules/README.md): 채택한 작업·판단 기준
- [작업 절차](guides/README.md): 반복 작업의 순서와 완료 기준
- [참고 자료](references/README.md): 외부 자료의 요약과 개인 해석
- [검증 사례](patterns/README.md): 실제 확인한 해결 방법과 적용 조건

[템플릿](../templates/README.md)을 복사해 문서를 작성합니다. [문서 형식](../docs/document-format.md)과 [검색·활용 기준](../docs/retrieval-policy.md)을 함께 확인합니다.

이 안내 파일과 하위 폴더의 `README.md`, `.gitkeep`은 지식 문서 색인 대상 밖입니다.
