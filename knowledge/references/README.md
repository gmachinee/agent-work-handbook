# 참고 자료

외부 자료의 요약, 출처, 개인의 해석과 활용 상황을 보관합니다. 정식 문서의 `kind`는 `reference`입니다.

- `ai/`: AI·에이전트 활용 자료
- `engineering/`: 소프트웨어 설계와 개발 자료
- `content/`: 콘텐츠 전략과 제작 자료
- `writing/`: 글쓰기, 조사, 편집 자료

[참고 자료 템플릿](../../templates/reference.md)을 복사하고 원문에서 확인한 내용과 개인의 해석을 구분합니다. 채택한 작업 기준은 별도의 지침 문서로 작성해 연결합니다.
