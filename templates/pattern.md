# 검증한 패턴의 구체적인 제목

## 문제

실제로 해결한 문제와 이전 상태를 작성한다.

## 적용 조건

확인한 작업 종류, 환경·버전, 입력 조건, 필요한 전제를 작성한다.

## 해결 방법

재사용할 수 있는 단계, 예제 또는 프롬프트를 작성한다. 예시는 공개용 데이터로 구성한다.

## 검증 방법과 결과

실제 수행한 검증, 확인한 결과, 근거 위치와 확인 날짜를 작성한다. 확인한 범위와 예상하는 범위를 구분한다.

## 한계

적용이 어려운 조건, 남은 위험, 추가 검증이 필요한 상황을 작성한다.

## 관련 문서

관련 규칙, 절차, 참고 자료의 상대 링크를 작성한다.
